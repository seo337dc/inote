# inote-blog — 화면별 작업 리스트 (Phase 1)

> `STRATEGY.md`의 Phase 1(블로그 뼈대)을 화면 단위로 쪼갠 작업 리스트.

## 화면 목록 (2026-09-03 확정)

1. 로그인 페이지
2. dev-guide 페이지 (만다라트)
3. 메인 홈페이지 — 모든 글 리스트 (공개)
4. 나의 글 리스트 페이지
5. 글쓰기 페이지
6. 내글 카테고리 수정 화면
7. 내 정보 화면

## 공통 선행 작업 (0순위)

모든 화면이 걸려있는 전제 작업 — 이것부터.

- [ ] `inote-server`에 `blog` 모듈 자리 만들기
- [ ] Prisma에 `Post`, `Category` 모델 추가 (`Post.authorId`로 유저와 연결)
- [ ] `inote-blog` Next.js 프로젝트 뼈대 세팅

## 화면별 작업

### 1. 로그인 페이지

| 항목 | 내용 |
|---|---|
| 목적 | Google/Naver 등으로 로그인 |
| FE | 로그인 버튼 → `inote-server`의 Better Auth OAuth 플로우로 리다이렉트 |
| BE | 신규 작업 거의 없음 — 기존 `inote-server` 인증 그대로 재사용 |
| 선행 조건 | Next.js 뼈대만 있으면 됨 |
| 비고 | 다른 "로그인 필요" 화면들의 전제. 제일 먼저 만드는 게 좋음 |

### 2. dev-guide 페이지 (만다라트)

| 항목 | 내용 |
|---|---|
| 목적 | 프로젝트 만다라트를 인앱에서 확인 |
| FE | `docs/mandalart.html`의 마크업·스타일을 Next.js 페이지로 이식 |
| BE | 없음 |
| 선행 조건 | 없음 |
| 비고 | BE 의존성이 전혀 없어서 **가장 먼저, 가장 빠르게 완성 가능**. 초반 워밍업 겸 첫 배포 확인용으로 좋음 |

### 3. 메인 홈페이지 — 모든 글 리스트 (공개)

| 항목 | 내용 |
|---|---|
| 목적 | 로그인 없이 누구나 보는 전체 글 목록 (devlog-llm 데모 페이지와 같은 성격) |
| FE | 글 목록 카드, 카테고리 필터 사이드바 (devlog-llm 패턴 재사용) |
| BE | `GET /blog/posts` — **인증 불필요**, 공개 |
| 선행 조건 | `Post`/`Category` 모델 |
| 비고 | 지금은 "전체 공개" 전제로 최소 구현. 비공개/초안 개념이 생기면 그때 필터링 추가 |

### 4. 나의 글 리스트 페이지

| 항목 | 내용 |
|---|---|
| 목적 | 로그인한 내 글만 모아보기 |
| FE | 홈과 비슷한 레이아웃 + "내 글만" 필터 |
| BE | `GET /blog/posts?mine=true` — 로그인 필요, `authorId` 기준 필터 |
| 선행 조건 | 로그인 완료, `Post.authorId` |
| 비고 | 여러 계정(Gmail/Naver)으로 각각 로그인했을 때 데이터가 잘 분리되는지 확인하는 화면이기도 함 (`PLANNING.md` 목표 1번) |

### 5. 글쓰기 페이지

| 항목 | 내용 |
|---|---|
| 목적 | 글 작성·발행 |
| FE | 에디터(Tiptap 등 — devlog-llm 재사용 검토), 카테고리 선택, 발행 버튼 |
| BE | `POST /blog/posts` |
| 선행 조건 | 로그인, `Post`/`Category` 모델 |
| 비고 | LLM 챗 UI는 이번 화면 목록엔 없음 — Phase 2에서 `inote-ai` 연동 시 이 페이지에 추가 예정 |

### 6. 내글 카테고리 수정 화면

| 항목 | 내용 |
|---|---|
| 목적 | 내 카테고리 목록 조회·추가·이름 변경 |
| FE | 카테고리 목록, 추가/수정 폼 |
| BE | `Category` CRUD API |
| 선행 조건 | 로그인, `Category` 모델 |

### 7. 내 정보 화면

| 항목 | 내용 |
|---|---|
| 목적 | 프로필 확인·수정 |
| FE | 프로필 표시, 수정 폼 |
| BE | 기존 `inote-server`의 유저 정보 API 재사용 여부 확인 필요 (`src/users/`) |
| 선행 조건 | 로그인 |
