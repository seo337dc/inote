## 5. 블로킹과 논블로킹을 직접 눈으로 보기
> **작성 가이드**: 실험 결과를 먼저 적고, 그다음 "왜"를 설명한다.

### 실험 B — 같은 5초인데 왜 다를까
```js
// server.js
const http = require('http');
http.createServer((req, res) => {
  if (req.url === '/block') {
    const end = Date.now() + 5000;
    while (Date.now() < end) {}                           // 5초 동안 스레드를 점유
    return res.end('block done');
  }
  if (req.url === '/async') {
    return setTimeout(() => res.end('async done'), 5000); // 5초 기다리지만 스레드는 자유
  }
  res.end('pong');
}).listen(3000);
```
