## 남긴 것
- [ ] **모델을 도커 이미지에 포함(굽기)** — 지금 `inote-embedder/Dockerfile`은 모델을 이미지에 넣지 않고 서비스가 시작할 때 `HF_HOME=/models`로 내려받는다(로컬 측정: 모델을 새로 받는 첫 시작 약 2분, 모델이 있을 때 재시작 약 15초). `inote-ai`의 임베딩 호출 상한이 40초라 그동안 들어온 임베딩은 빠진다.
  - **호스트에 따라 필요성이 다르다.** 재시작·중지 때마다 **디스크가 초기화되는 곳**(Hugging Face Spaces 등)에서는 깨어날 때마다 모델을 다시 받으므로 필요하다. 디스크가 유지되는 VM(Oracle 계획)이면 모델이 남아 재시작이 빠를 수 있어 우선순위가 낮다 — **추측**이며 배포 후 확인한다.
  - 이미지에 모델을 넣으면 시작이 짧아지지만 이미지가 커진다(HF의 이미지 크기 한도는 **확인 못 함**).
  - 결정은 호스트가 정해진 뒤에 한다.
