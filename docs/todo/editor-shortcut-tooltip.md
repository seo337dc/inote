# 에디터 단축키 말풍선 — 이번에 제외한 것

> 2026-11-13. 툴바 버튼에 마우스를 올리면 이름과 단축키(맥 ⌘⌥⇧ / 윈도우 Ctrl+Alt+Shift)를 보여주는 기능을 1차로 넣었다.
> 대상은 굵게·기울임·취소선·목록·체크박스·인용·인라인 코드·코드 블록 8개. 표시하는 단축키는 모두 Tiptap 기본값이고
> `toolbar-shortcuts.ts`가 출처, `toolbar-shortcuts.test.ts`가 "실제 확장에 등록돼 있는지"를 확인한다.

## 후속
- [ ] **H1~H4**: 단축키(Mod-Alt-1~4)는 Tiptap 기본 동작이고, 툴바 버튼은 줄바꿈으로 이어진 문단에서 누른 줄만 제목으로 바꾸는 `toggleHeadingOnLine`을 쓴다. 둘의 동작이 다르다. 단축키도 같은 동작으로 맞춘 뒤(에디터 확장에 키 바인딩 추가) 말풍선을 붙인다. 지금은 일부러 표시하지 않는다
- [ ] **단축키가 없는 버튼**(링크·표·콜아웃·이미지): 말풍선 없음(기존 브라우저 툴팁 `title`만). 링크에 관례인 ⌘K를 추가할지 정한다 — 기능 추가라 사용자가 결정
- [ ] **다른 메뉴**: 텍스트 선택 시 뜨는 버블 메뉴(`SelectionBubbleMenu`), 표 편집 툴바(`TableToolbar`)에도 같은 말풍선을 붙일지
- [ ] 툴바에 버튼이 없는 단축키: 번호 목록(Mod-Shift-7), 밑줄(Mod-u)은 단축키만 있다 — 버튼을 만들 때 같이 표시
- [ ] 좁은 화면 `…` 팝오버와 터치 기기: hover가 없어 말풍선을 붙이지 않았다
- [ ] 브라우저에서 말풍선 모양·위치(툴바 아래 `bottom`)·뜨는 지연(0.4초)을 직접 확인 — jsdom으로는 확인할 수 없다

## 구조 점검에서 미룬 것 (refactor-advisor, 2026-11-13)
- [ ] `ToolbarButton`의 `hint={{ label, shortcut }}`와 `label`이 같은 문자열을 두 번 받는다(아이콘 버튼). `hint`를 `shortcut?: string` 하나로 줄이고 `label`을 재사용하는 안(B)이 있으나, B·I·취소선 버튼에 `aria-label`이 붙어 접근 가능한 이름이 "B" → "굵게"로 바뀌고 기존 테스트(`getByRole("button", { name: "B" })`)를 고쳐야 한다. 이름 접근성까지 같이 개선할 때 함께 한다
- [ ] 단축키 정보가 세 곳에 나뉘어 있다: 키는 `toolbar-shortcuts.ts`, 앞쪽 글자 버튼(B·I·취소선)의 이름은 `PostEditor.tsx`, 아이콘 버튼의 이름은 `toolbar-items.ts`. 앞쪽 그룹(H1~H4·B·I·취소선)을 배열로 바꿀 때 함께 정리
- [ ] `shortcut.ts`의 순서 상수 4개와 맥/그 외 두 갈래 분기 — 플랫폼 표기가 하나 더 필요해질 때 손본다
- [ ] `navigator.platform` mock이 두 테스트 파일에 방식이 다르게(`spyOn`·`stubGlobal`) 있다 — 세 번째가 생기면 `src/test/`로
