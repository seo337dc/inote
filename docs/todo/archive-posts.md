# 후속 작업 — 글 보관함

> 글 보관함(`docs/adr/0007-archive-posts.md`)을 하면서 **이번에는 하지 않고 남긴 것**을 모은다. (계약은 2026-10-27 승인, FE·BE·로컬 통합 확인 완료)
> 앞으로 "나중에 하기로 한 기능"은 모두 `docs/todo/`에 기록한다.

## ⚠️ 임베딩을 켜기 전에 반드시 (보류 항목)
- [ ] **보관한 글을 비슷한 글 후보에서 제외** — `inote-server`의 `embedding-candidates.ts`의 공개/열람/내 글 후보 조건(`publicCandidatesWhere`·`readableCandidatesWhere`·`ownCandidatesWhere`)과 `findSimilar`가 후보 글을 다시 읽는 조회에 `archivedAt: null`을 넣는다. 지금은 임베딩이 운영에서 꺼져 있어(`EMBEDDINGS_ENABLED=false`) 작업하지 않지만, **켜기 전에 하지 않으면 보관한 글이 남에게 추천될 수 있다.** 벡터는 지우지 않고 후보에서만 뺀다(해제하면 바로 복귀). (이미 한 것: `findSimilar`의 **원본 글** 검사와 `public-ids` 목록의 제외 — ADR 10절)
- [ ] **보관한 글의 임베딩 동기화** — 보관·해제 때 벡터를 지우거나 다시 만들지는 않는다. 임베딩을 켤 때 위 항목과 함께 정책을 확인한다.
