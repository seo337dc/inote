# 에디터 이미지 크기 조절 UX

> 시작 2026-11-19. 세션이 바뀌어도 이어 갈 수 있게 하는 작업 지시서다. 끝나면 삭제한다(`/wrap`).

## 목표
세로로 긴 이미지(100%)는 크기 핸들이 `top-1/2`(이미지 세로 중앙)라 화면 밖에 있어 줄일 수 없다. 조절 장치가 항상 보이게 한다.
- 이미지를 선택하면 이미지 안쪽 위에 `sticky`로 고정된 프리셋 툴바(25·50·75·100%)가 뜬다 (스크롤해도 따라옴).
- 드래그 핸들은 세로 중앙 대신 오른쪽 위 모서리로 옮기고 키운다(원형 약 16px).
- 마우스 환경 기준. 키보드 크기 조절은 이번 범위 밖.
