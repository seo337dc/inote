# 글을 임시저장으로 되돌리기 + 임시저장 목록 화면

> 2026-11-11 시작. 발행해 둔 글 중 아직 미완성인 글을 임시저장(draft)으로 되돌리고, 임시저장 글만 모아 보는 화면을 따로 만든다.
> 순서: ① 계약(이 문서) → ② FE(MSW 목, **화면은 하나씩 의논한 뒤 만든다**) → ③ BE(Claude는 테스트 목록·골격만, 사람이 작성) → ④ 통합(로컬 개발 DB에서만). 배포는 BE 먼저.

## 현재 구조 (2026-11-11 코드 확인)
- 임시저장(draft) = `Post.publishedAt`이 null인 글. 제목·본문이 모두 비어 있는 빈 draft(글쓰기 화면에 들어오기만 해도 생김)는 목록에서 draft로 치지 않는다(`EMPTY_DRAFT`).
- 발행된 글을 draft로 되돌리는 경로가 **없다**(`PATCH`의 `publish: true`는 발행만 한다).
- 임시저장 목록 화면이 **없다** — draft는 글쓰기 화면에 들어갈 때 뜨는 `DraftListModal`에서만 보이고, `GET /blog/posts/mine/drafts`(페이지네이션 없이 전부, 본문 포함)가 이미 있다.
- `나의 글`(`GET /blog/posts/mine`)은 빈 draft만 빼고 **내용이 있는 draft도 포함**하며, 목록에서 발행글과 구분하는 표시가 없다.
- 참고 패턴: 보관 기능(`archivedAt`, `/my-posts/archive`).

## 결정 (2026-11-11, 사용자 확인)
- 변경 진입점: **글 상세 화면의 `⋯` 메뉴**에서 한 편씩(작성자 본인에게만 보인다). 나의 글 목록의 일괄 선택은 이번에 하지 않는다.
- 글 상세 메뉴 구성: 수정은 밖의 링크로 두고, **고정·보관·임시저장으로 변경·삭제**를 `⋯` 메뉴 한 목록으로 모은다. 임시저장(발행 전) 글에는 삭제만 보이고, 보관한 글은 "임시저장으로 변경"이 비활성("보관 해제 후 가능"). 임시저장으로 변경·삭제는 확인창을 거친다.
- 임시저장으로 바꾼 뒤: 안내 토스트 후 **`/my-posts/drafts`(임시저장 목록)으로 이동**한다 — 그래서 이 메뉴는 목록 화면과 같은 PR로 나가야 한다(목록이 없으면 404).
- 되돌릴 때: 발행일은 비우고(다시 발행하면 그 시각이 새 발행일), 고정은 풀고, 비공개 설정·카테고리·썸네일·AI 요약·메모는 그대로 둔다. **보관한 글은 거절**(먼저 보관 해제). 임베딩은 지우지 않는다 — 임베딩 후보는 발행된 글만 쓰므로 draft가 된 글은 유사 글에 나오지 않는다.
- `나의 글`(`/my-posts`)은 **발행한 글만** 보여주고, 임시저장 글은 나의 글의 **[임시저장] 탭**(`/my-posts/drafts`, 탭 순서: 나의 글 · 임시저장 · 보관함)에서만 보인다.
- 임시저장 탭 목록 데이터: **기존 `GET /blog/posts/mine/drafts` 그대로**(서버 변경 없음). 그래서 이 탭에는 나의 글과 달리 카테고리 필터·검색·페이지네이션이 없다.
- 임시저장 목록의 글을 누르면 **이어 쓰는 화면(`/write/:id`)**으로 간다.
- 임시저장 탭에서의 **삭제는 이번에 만들지 않는다**(후속) — 이어 쓰기 화면·글 상세 메뉴의 기존 삭제를 쓴다.

## API 계약 (확정 2026-11-11)

### `POST /blog/posts/:id/unpublish` (신규, 로그인 필요, 본인 글만)
| 항목 | 내용 |
|---|---|
| 성공 | 200, 응답은 `PATCH /blog/posts/:id`와 같은 글 상세 모양(FE 캐시 갱신용). 이미 draft여도 그대로 200(멱등) |
| 처리 | `publishedAt = null`, `lastEditedAt = null`(draft 규칙), `pinned = false`. 나머지는 그대로 |
| 오류 | 401 비로그인, 403 남의 글, 404 없는 글, **409 보관한 글**("보관을 해제한 뒤 임시저장으로 바꿀 수 있습니다" 류) |
| 다시 발행 | 기존 `PATCH publish: true`가 그대로 쓰인다(`publishedAt = now`) |
- `:id` 경로는 `archive`·`unarchive`처럼 고정 경로가 아니라서 선언 순서 문제는 없다.

### `GET /blog/posts/mine` (변경)
- **발행한 글만** 돌려준다(`publishedAt != null`). 임시저장 글은 빠진다. 페이지 총합(`total`)과 사이드바 카테고리 개수(`categoryCounts`)도 발행한 글 기준이다(보관함 모드 `archived=true`는 원래 발행글만이라 그대로).

### `GET /blog/posts/mine/drafts` (그대로)
- 빈 draft를 뺀 내 임시저장 글 전체(최근 수정순). 새 화면이 쓴다. 페이지네이션 필요 여부는 화면 의논 때 정한다.
