## 우선순위 높음 (이 기능과 함께 쌓이는 문제)
- [ ] **고아 파일 정리 배치** — 저장 안 하고 나간 업로드, 글에서 지운 이미지, 삭제된 글의 이미지가 R2에 남는다. 기존 설계 `docs/blog/image-upload-r2-orphan-files.md` 5-3(참조 기반: DB 어디에서도 참조하지 않고 24시간 지난 `tmp/`·`post/` 파일 삭제)을 글 이미지에도 적용. 참조 판단은 **모든 글(`Post.content`)의 `<img src>`** 기준.
- [ ] **글 삭제 시 이미지 삭제** — `post/<userId>/<postId>/` 접두어 일괄 삭제(`postId` 폴더를 둔 이유). 정리 배치가 생기기 전의 임시 방편으로도 가능.
- [ ] **승격 실패 재시도·알림** — 복사가 실패하면 tmp 주소로 남는다(fail-open). 정리 배치가 "참조 중인 tmp"는 지우지 않지만, 영구 폴더로 옮기는 재시도 경로와 실패 건수 보고가 필요하다.

## 에디터 기능
- [ ] 이미지 **정렬**(왼쪽/가운데/오른쪽) — 가운데 정렬을 넣을 때 왼쪽 핸들(양쪽 리사이즈)도 함께 검토
- [ ] 올리는 중 이미지가 있는 상태에서 자동저장이 돌면 그 자리는 저장 HTML에서 빠진다(업로드 끝나기 전 이탈 시 이미지 유실) — 저장 전 업로드 완료 대기 또는 경고 검토
- [ ] 이미지 **캡션**, **alt 텍스트** 편집
- [ ] **키보드로 크기 조절**(핸들 포커스 + 방향키) — 접근성
- [ ] 이미지 **확대 보기**(라이트박스) — 읽기 화면
- [ ] **여러 장 동시 업로드**, 업로드 **진행률** 표시
- [ ] 이미지 **위치 이동**(드래그로 단락 사이 이동) 확인·정리

## 범위 확장
- [ ] **독서 기록 에디터**에도 이미지 삽입 — 기존 `reading/` 폴더 규칙·승격 시점과 함께 설계
- [ ] 글 **썸네일**도 같은 tmp → 승격 구조로 통일(지금은 `uploads/<userId>/...`에 바로 올림)

## 보안·정책
- [ ] **외부 이미지 URL**을 본문에 허용할지(지금은 건드리지 않고 그대로 둠). 허용 목록 또는 우리 R2만 허용
- [ ] **비공개 글의 이미지 접근 제어** — 공개 URL이라 주소를 아는 사람은 볼 수 있다(서명 URL 등 검토)
- [ ] 공개 URL이 **개발용 `r2.dev`**이면 운영에 권장되지 않음(공식 문서 확인 필요) → 커스텀 도메인, 그리고 **본문에 URL 전체가 아니라 키만 저장**하는 안

## 성능·비용
- [ ] 업로드 전 **리사이즈·WebP 변환**으로 용량 줄이기, 큰 이미지는 `srcset` 등
- [ ] 이미지 로딩 시 **레이아웃 밀림 방지**(원본 가로세로 크기를 알아 두기)
